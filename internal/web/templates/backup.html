Backup

{{/* The one page here that is a program rather than a document (#337): with no script there is nothing to show but why, and a browser that cannot keep a folder is told so rather than offered a button that does nothing. backup.js decides which of the two halves below is shown. */}}

This browser cannot keep hold of a folder on this computer, so it cannot back one up. Chrome and Edge on a desktop can; Firefox, Safari and every browser on a phone cannot.

Without one, a folder is backed up by a client that speaks WebDAV: rclone, Finder, or the Stratus app for a phone's camera roll.

Pick a folder once and this page copies into Stratus whatever in it is not here yet, and does it again every time the page is opened. It only ever adds: nothing is deleted or replaced on either side, and a file deleted here after it was copied is not copied again.

Another tab is backing up already. This one waits for the next visit.
